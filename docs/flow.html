        Method and limits

        The ranking uses only the public subset of a seven-day top-20 source aggregation. Country labels come from existing IP enrichment and may be missing, cached, or point to hosting, a proxy or shared infrastructure. They do not identify a person or an attack’s origin.

        The default display groups the original CN, TW and HK labels under China. The detail panel preserves the original counts; Original labels splits them. This changes reporting only, not the underlying labels or map boundaries.

        Lookup coverage is the number of displayed source rows with at least one successful provider result marked fresh at batch time, divided by all displayed rows in the selected group. It is not a score, the freshness of the country label, or evidence of compromise. The daily trend is for all Wazuh alerts and is not available by country.

        Samples are labels attached to source rows, not per-behavior alert counts. MISP membership and provider coverage are context, not confirmation. No sensor identities, sensor locations, individual addresses or target paths are shown in this view.

        Read-only batch report · Uses only existing public snapshot files · No new lookups or live sensor access.
